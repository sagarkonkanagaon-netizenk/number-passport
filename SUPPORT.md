# Getting help

| You want to | Go to |
|-------------|-------|
| Understand how a number was reconciled | [docs/how-it-works.md](docs/how-it-works.md) |
| Configure a project or a connection | [docs/configuration.md](docs/configuration.md) |
| Get security approval | [docs/security.md](docs/security.md) |
| Ask a question | [Open a question](https://github.com/sagarkonkanagaon-netizenk/number-passport/issues/new?template=question.yml) |
| Report a bug | [Open a bug report](https://github.com/sagarkonkanagaon-netizenk/number-passport/issues/new?template=bug_report.yml) |
| Request a feature or connector | [Open a feature request](https://github.com/sagarkonkanagaon-netizenk/number-passport/issues/new?template=feature_request.yml) |
| Report a vulnerability | [SECURITY.md](SECURITY.md) (privately, never in an issue) |

Before opening a bug, please run `passport doctor` and include its output. It checks every connection point
and usually names the problem.

**Never paste customer data, credentials or connection strings into an issue.** Evidence packs contain no
customer rows, but they do contain table names and code excerpts; share them only if that is acceptable to
your organization.
